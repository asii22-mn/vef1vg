# Gullni hringurinn — verkefni 7

Íslenskur vefur með forsíðu og sex undirsíðum. Engar pakkauppsetningar eru nauðsynlegar.

## Keyrsla

Keyrðu úr rót geymslunnar:

```sh
python3 -m http.server 8000
```

Opnaðu `/verkefni-7/index.html` í vafra. Forsíðumyndir hverfa þegar skjábreidd er 600 px eða minni. Myndir á undirsíðum haldast sýnilegar og laga sig að skjástærð.

Myndirnar eru staðbundnar ljósmyndir frá Wikimedia Commons. Höfundar og leyfi eru skráð á `myndheimildir.html`. Myndin við Gljúfrastein sýnir Mosfellsdal, ekki húsið sjálft. Google Maps kortið þarfnast nettengingar.

## GitHub Pages

Til að birta á `https://asii22-mn.github.io/verkefni-7/index.html` þarf mappan `verkefni-7` að vera í rót geymslunnar `asii22-mn.github.io`. Settu skrárnar þangað og veldu viðeigandi grein og rótarmöppu í Settings → Pages.

Ef þessi geymsla, `vef1vg`, er birt beint með GitHub Pages verður slóðin venjulega `https://asii22-mn.github.io/vef1vg/verkefni-7/index.html`. Það er önnur slóð en skilalýsingin biður um.

Skrárnar hafa ekki verið sendar á GitHub eða birtar sjálfkrafa.
